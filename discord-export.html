Discord Export

Save a channel or thread as a text / JSON / CSV file. Based on DiscordChatExporter, with a thread picker added. Runs in your browser: the token goes to Discord only, never to this site.

Read first. A bot token (a bot you added to the server) is the allowed way. Using your own account's token breaks Discord's terms of service and can get the account banned, so only do it for reading content you already can see, in small amounts, and at your own risk. The token is kept in memory only unless you tick “remember”. See the DiscordChatExporter docs (Token and IDs guide) for where tokens come from.
